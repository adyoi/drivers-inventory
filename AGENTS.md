# Drivers inventory project

## Commands

Regenerate everything (reads live `C:\Windows\System32\drivers`, writes `README.md`, `tools/drivers_inventory.csv`, `docs/index.html`):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\gen_docs.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\gen_readme.ps1
```

## Structure

- `README.md` — summary inventory (generated by `gen_readme.ps1`)
- `docs/index.html` — single-file interactive browser page (generated by `gen_docs.ps1`)
- `docs/.nojekyll` — GitHub Pages bypass
- `tools/gen_docs.ps1` — generates HTML + CSV
- `tools/gen_readme.ps1` — generates README + CSV
- `tools/common.ps1` — shared categories, rules, and deep-dive definitions
- `tools/drivers_inventory.csv` — raw inventory data (generated)
- `LICENSE` — MIT

## Notes

- No git repo in this directory; `docs/index.html` and `tools/drivers_inventory.csv` are generated artifacts and listed in `.gitignore` if versioned elsewhere.
- Both scripts require Windows PowerShell 5.1+ and read from `C:\Windows\System32\drivers` (Windows Resource Protection — read only).
